# CodeClass

پلتفرم مدیریت کلاس و تمرین‌های برنامه‌نویسی که به دانشجویان اجازه می‌دهد کد پایتون خود را ارسال کنند و اساتید آن‌ها را بررسی و بازخورد بدهند.

## وضعیت فعلی (در حال توسعه)

پروژه در مراحل اولیه توسعه است. بخش‌های کلیدی زیر تاکنون پیاده‌سازی شده‌اند:

- احراز هویت (ورود / خروج) مبتنی بر کاربران Django
- مدل `Submission` برای ثبت و بررسی ارسال‌های کد دانشجویان
- داشبورد ساده برای کاربران (`/dashboard/`)
- پنل ادمین Django برای مدیریت ارسال‌ها

> توجه: محیط اجرای کد فعال است (کد اجرا می‌شود)، اما ثبت (Submit) ارسال‌ها برای بررسی استاد هنوز پیاده‌سازی نشده.

## ساختار پروژه

```
ClassCode/
├── manage.py              # ابزار خط فرمان Django
├── requirements.txt       # وابستگی‌های پروژه
├── codeclass/             # تنظیمات و کانفیگ اصلی پروژه (settings, urls, ...)
├── core/                  # اپلیکیشن اصلی
│   ├── models.py          # مدل Submission
│   ├── views.py           # داشبورد و منطق نمایش
│   ├── urls.py            # مسیرهای (routes) اپلیکیشن
│   ├── admin.py           # ثبت مدل‌ها در پنل ادمین
│   └── templates/core/    # قالب‌های HTML (login, dashboard)
└── db.sqlite3             # دیتابیس محلی (SQLite)
```

## اجرای پروژه به‌صورت محلی

پیش نیاز: پایتون 3 نصب شده باشد.

```bash
# 1) ساخت و فعال‌سازی محیط مجازی
uv venv
uv sync                      # یا: pip install -r requirements.txt

# 2) اعمال مهاجرت‌ها روی دیتابیس
python manage.py migrate

# 3) (اختیاری) ساخت کاربر ادمین
python manage.py createsuperuser

# 4) اجرای سرور توسعه
python manage.py runserver
```

سپس به آدرس‌های زیر دسترسی خواهید داشت:

- پنل ادمین: `http://127.0.0.1:8000/admin/`
- داشبورد: `http://127.0.0.1:8000/dashboard/`

## مدل داده

### `Submission`
| فیلد | نوع | توضیح |
|------|-----|-------|
| `student` | FK → User | دانشجویی که ارسال را انجام داده است |
| `title` | CharField | عنوان ارسال (اختیاری) |
| `code` | TextField | کد پایتون ارسالی |
| `output` | TextField | خروجی اجرا (اختیاری) |
| `created_at` | DateTimeField | زمان ایجاد (خودکار) |
| `reviewed` | BooleanField | وضعیت بررسی‌شدن توسط استاد |
| `instructor_note` | TextField | بازخورد استاد (اختیاری) |

## مسیرهای (URL) موجود

| مسیر | نام | توضیح |
|------|-----|-------|
| `/` | `login` | صفحه ورود |
| `/logout/` | `logout` | خروج کاربر |
| `/dashboard/` | `dashboard` | داشبورد کاربر |
| `/admin/` | — | پنل ادمین |
| `/run/` | `run_code` | اجرای کد پایتون ارسالی (AJAX) |

## تکنولوژی‌ها

- **Python** + **Django 6.1**
- **SQLite** (دیتابیس پیش‌فرض)
- مدیریت وابستگی با **uv**
