# کلاس پایتون (CodeClass)

پلتفرم ساده‌ی مدیریت کلاس برنامه‌نویسی پایتون: کارآموزها با نام‌کاربری و رمزی
که مدرس از قبل برایشان ساخته وارد سامانه می‌شوند، در یک محیط کدنویسی داخل
مرورگر کد پایتون می‌نویسند و اجرا می‌کنند، و می‌توانند اسکریپت‌شان را برای
بررسی و بازخورد مدرس ثبت کنند.

## ویژگی‌ها

- ورود بدون صفحه‌ی ثبت‌نام — حساب هر کارآموز را مدرس از قبل می‌سازد
- محیط کدنویسی پایتون داخل مرورگر با اجرای زنده‌ی کد (بدون رفرش صفحه)
- ثبت اسکریپت برای بررسی مدرس، همراه با آخرین خروجی اجرا
- پنل مدرس: فهرست کارآموزها، تعداد اسکریپت‌های هرکدام، و مشاهده‌ی جزئیات
- امکان ثبت یادداشت/بازخورد مدرس روی هر اسکریپت و علامت‌گذاری «بررسی‌شده»
- پنل ادمین Django برای مدیریت کامل داده‌ها
- ظاهر تیره‌ی الهام‌گرفته از محیط ترمینال

## اجرای پروژه به‌صورت محلی

پیش‌نیاز: پایتون ۳ نصب شده باشد.

```bash
# 1) ساخت و فعال‌سازی محیط مجازی + نصب وابستگی‌ها
uv venv
uv sync

# 2) اعمال مهاجرت‌ها روی دیتابیس
python manage.py migrate

# 3) ساخت حساب مدرس (خودتان)
python manage.py createsuperuser

# 4) ساخت حساب برای هر کارآموز (بدون صفحه‌ی ثبت‌نام)
python manage.py add_student ali 123456

# 5) اجرای سرور توسعه
python manage.py runserver
```

سپس به آدرس‌های زیر دسترسی خواهید داشت:

- ورود کارآموز/مدرس: `http://127.0.0.1:8000/`
- پنل مدرس: `http://127.0.0.1:8000/instructor/`
- پنل ادمین Django: `http://127.0.0.1:8000/admin/`

## مدل داده

### `Submission`

| فیلد | نوع | توضیح |
|------|-----|-------|
| `student` | FK → User | کارآموزی که ارسال را انجام داده است |
| `title` | CharField | عنوان ارسال (اختیاری) |
| `code` | TextField | کد پایتون ارسالی |
| `output` | TextField | خروجی اجرا هنگام ثبت (اختیاری) |
| `created_at` | DateTimeField | زمان ایجاد (خودکار) |
| `reviewed` | BooleanField | وضعیت بررسی‌شدن توسط مدرس |
| `instructor_note` | TextField | بازخورد مدرس (اختیاری) |

## مسیرهای (URL) موجود

| مسیر | نام | توضیح |
|------|-----|-------|
| `/` | `login` | صفحه ورود |
| `/logout/` | `logout` | خروج کاربر |
| `/dashboard/` | `dashboard` | محیط کدنویسی و لیست اسکریپت‌های کاربر |
| `/run/` | `run_code` | اجرای کد پایتون ارسالی (AJAX) |
| `/submit/` | `save_submission` | ثبت کد و خروجی به‌عنوان یک ارسال |
| `/instructor/` | `instructor_overview` | فهرست کارآموزها برای مدرس |
| `/instructor/student/<id>/` | `instructor_student_detail` | اسکریپت‌های یک کارآموز خاص |
| `/instructor/submission/<id>/review/` | `mark_reviewed` | ثبت بررسی/یادداشت مدرس روی یک اسکریپت |
| `/admin/` | — | پنل ادمین |

## نکته‌ی امنیتی درباره‌ی اجرای کد

کد هر کارآموز در یک زیرفرآیند (subprocess) جدا و با محدودیت زمانی
(پیش‌فرض ۵ ثانیه) اجرا می‌شود تا حلقه‌ی بی‌نهایت یا کد سنگین سرور را قفل
نکند. این یک sandbox امنیتی کامل نیست — کد هنوز به فایل‌سیستم و شبکه
دسترسی دارد — و برای کلاسی با کارآموزهای شناخته‌شده مناسب است، نه برای
کاربران ناشناس اینترنت. برای استفاده در مقیاس بزرگ‌تر، بهتر است اجرای کد
داخل یک Docker container ایزوله (بدون دسترسی شبکه) قرار گیرد.

## تکنولوژی‌ها

- **Python** + **Django 6.1**
- **SQLite** (دیتابیس پیش‌فرض)
- مدیریت وابستگی با **uv**
- بدون فریم‌ورک فرانت‌اند اضافه — جاوااسکریپت خالص (Vanilla JS) با `fetch`
